# ساختار پروژه

```
├── index.html               ← تنها فایل HTML (نقطه شروع)
├── public/                  ← فایل‌هایی که همان‌طور که هستند سرو می‌شوند
│   └── img/logo.png         ← لوگو/favicon را اینجا بگذار
├── src/
│   ├── main.jsx             ← نقطه ورود: فقط import می‌کند و React را سوار می‌کند
│   ├── App.jsx              ← کامپوننت اصلی React
│   ├── components/
│   │   └── Calculator/      ← هر کامپوننت پوشه‌ی خودش را دارد
│   │       ├── Calculator.jsx
│   │       └── mohasbe.js   ← منطق محاسبه (جدا از ظاهر)
│   ├── scripts/             ← جاوااسکریپت‌های ساده (انیمیشن، منو، ...)
│   ├── styles/              ← همه‌ی CSSها
│   └── assets/fonts/        ← فونت‌های Inter را اینجا بگذار
└── _unused/                 ← باقی‌مانده‌ی قالب Vite؛ بعد از اطمینان پاک کن
```

## قوانین ساده
1. کد جدید React → `src/components/<Name>/`
2. یک فایل، یک کار (ظاهر جدا، منطق جدا)
3. هر CSS و JS فقط یک‌بار و فقط از `src/main.jsx` لود می‌شود (نه با `<link>` و `<script>` داخل HTML)
4. `output.css` را دستی ویرایش نکن؛ Tailwind آن را می‌سازد
5. فایل‌های بدون استفاده را در پروژه نگه نداری

## 📌 درباره پروژه (About The Project)

این **اولین پروژه من** است! مسیر توسعه این وب‌سایت با زبان‌های پایه وب یعنی **HTML، CSS و JavaScript** شروع شد و در ادامه برای توسعه پیشرفته‌تر، آن را به **React** منتقل کردم. 

من از این پروژه به عنوان یک **آزمایشگاه شخصی (Personal Lab)** استفاده می‌کنم. هر زمان که موضوع، ابزار یا تکنولوژی جدیدی در دنیای فرانت‌اند یاد می‌گیرم، دست به کار شده و آن را روی این پروژه پیاده‌سازی و تست می‌کنم تا تجربیاتم را به صورت عملی رشد دهم.

---

## ✨ امکانات فعلی (Current Features)

- 🔐 **صفحه ورود (Login Page):** طراحی رابط کاربری برای بخش ورود کاربران.
- 🧮 **ماشین‌حساب کاربردی (Calculator):** ابزار محاسباتی همراه با منطق تفکیک‌شده.
- 🎨 **طراحی و استایل مدرن (Modern UI):** بهره‌گیری از تم تمیز، رنگ **فیروزه‌ای جذاب** و افکت‌های بصری.
- 🎭 **انیمیشن‌های روان (Animations):** جلب توجه کاربر و تعامل بهتر با بخش‌های مختلف سایت.

---

## 🛠️ تکنولوژی‌های استفاده‌شده (Tech Stack)

- **کتابخانه اصلی:** React.js
- **استایل‌دهی:** Tailwind CSS / CSS3
- **زبان پایه:** JavaScript (ES6+)
- **بندلر / ابزار توسعه:** Vite
